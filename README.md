# Employee Management System - Frontend

## 🛠 Tech Stack

* React
* Axios

## 🚀 Features

* Add Employee
* View Employees (Table)
* Update Employee
* Delete Employee

## ⚙️ Setup Instructions

### 1. Clone repository

git clone https://github.com/your-username/employee-frontend.git

### 2. Install dependencies

npm install

### 3. Run project

npm start

### 4. Open in browser

http://localhost:3000 (or 3001)

## 🔗 Backend Requirement

Backend must be running at:
http://localhost:8081
